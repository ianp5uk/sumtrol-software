How it works

The interface and solver are plain HTML, CSS and JavaScript inside a small Kotlin wrapper. The app requests no Android permissions (no internet, sensors or storage) and uses no third-party code beyond the Android framework and the Kotlin standard library.

Supported drag models: G1, G2, G5, G6, G7, G8, GI, GL and RA4. Defaults: BC 0.112, RA4.

Accuracy

Designed for 10 to 100 m smallbore. It solves to 3,000 m, with falling accuracy beyond about 500 m. The algorithms and the source of every drag table are documented in ALGORITHMS.md in the source code.

Install with adb

adb install Ballisto-1.0.2.apk

Updates install over earlier versions and keep your saved ammunition and rifles.
