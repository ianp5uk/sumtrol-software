Is this for me?

Costing is really an online spreadsheet to solve the problem of calculating costs for team projects.

It's designed for use in a web browser on any device with an internet connection. It stores the data in a database, automatically versioning it.

  • Team working, sharing control, templating, auto versioning & private or public hosting.
  • Still being developed but a basic version is available for demonstration purposes.
  • Utilises spreadsheet technology and syntax for familiarity.

What you need

  • A private or dedicated cloud hosting environment
  • Time to setup
  • Or...use our shared instance
