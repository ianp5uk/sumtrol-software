How it works

The installer adds a small local helper that relays requests to the X API, and a JavaScript interface that runs in your default browser. Launch it from the menu or with tweetdelete in a terminal. The helper continues deleting in the background if the browser is closed, and resumes when restarted.

Authentication uses OAuth with your own X developer client ID.

Limitations

  • X's search limit (about 3,200 recent items) means larger histories need the X archive file.
  • X rate-limits deletions and charges per API call.
  • The name "TweetDelete" is used by another service on X, so the app appears as XTweetDelete in X's developer console.
